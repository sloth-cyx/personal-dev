# 静阅 Android 1.0.1 — 验证记录

日期：2026-10-26，Asia/Kuala_Lumpur。

## 已通过

### 编译与安装包结构

- Java 17 编译，Android API 35 平台、Build Tools 35.0.0。
- `minSdkVersion=26`（Android 8.0），`targetSdkVersion=35`。
- 正式签名验证通过：APK Signature Scheme v2 和 v3，RSA 3072。
- 应用包名 `com.jingyue.reader`，版本 `1.0.1` / `10001`。
- 无联网权限，无广泛存储访问权限；文件由系统文件选择器提供。
- 内置字体、字体许可、页面脚本和样式均已打入 APK。

### 解析与长文

独立 JVM 测试通过 18 项检查，另一次图文样本检查通过 19 项（包含重复的 12 项基础检查，不能将两组相加作为独立测试数）。

覆盖 UTF-8、UTF-16 BOM、GB18030、长行代理对不破坏、Markdown 可读正文、EPUB 元数据和 EPUB3 目录锚点、DOCX 自定义标题继承及明确正文覆盖、FB2、HTML 脚本排除、18 万段正文流式索引及末尾随机读取。

用户提供的五个样本均成功解析：

| 样本 | 正文块 | 目录项 |
| --- | ---: | ---: |
| 《花嫁》 至洊雷篇06.epub | 20,062 | 34 |
| 诡秘之主.txt | 118,756 | 1,409 |
| 诡秘之主_章节排版版.docx | 117,302 | 1,463 |
| 黎明之剑.txt | 89,740 | 1,595 |
| 黎明之剑_章节排版版.docx | 88,141 | 1,601 |

自制图文 EPUB 提取 3 张插图；自制 DOCX 尾部图片回归样本提取 20 张插图、5 个自定义章节标题。用户的小说内容没有包含在交付包中。

18 万段测试在此 Windows 电脑的 JVM 上约 0.2–0.5 秒完成解析和索引；这是桌面解析测试，不是手机启动速度或手机导入性能承诺。

### 手机尺寸的界面与交互

Playwright + Chrome，393×851、360×740 竖屏以及 851×393 横屏，内置文楷实际加载。通过：

- 圆角书库、圆角字体下拉、暖砂／深夜主题。
- 连续阅读段内位置保存并重新打开。
- 全局书签跳回收藏位置。
- 图片尾部 100% 向上滚动后保持位置，不弹回底部。
- 左右分页、段内字符位置恢复，末页图片不被边缘截断。
- 分段边界前进／后退没有跳过正文块。
- 触摸横扫翻页，中间轻点隐藏／恢复工具栏。
- 横屏无视口横向溢出。
- 删除取消保留书籍，确认删除后空书库正确呈现。
- 未发现页面脚本运行错误。

原始输出见 `验证输出` 目录。截图为 Chrome 手机尺寸布局预览，不是 Android 真机截图。
