# 静阅 Android 1.0.2

交付日期：2026-10-26（Asia/Kuala_Lumpur）。支持 Android 8.0 及以上，通用 APK，不区分 ARM / x86，不需要登录或联网。

## 安装与导入

把 `JingYue-Android-1.0.2.apk` 传到手机后，使用手机文件管理器打开安装。若系统要求，请为你使用的文件管理器允许安装此来源的应用。本应用是直接安装包，尚未上架应用商店。

打开静阅，点底部「＋ 导入书籍」，在系统文件选择器中选择小说文件，可以一次选择多本。也可以从其他应用通过「分享」发送支持的文件到静阅。

支持 TXT、MD / MARKDOWN、EPUB、DOCX、HTML / HTM、FB2。单本来源文件上限 250 MB，压缩书籍解压总大小上限约 350 MB。DRM 加密电子书、PDF、MOBI / AZW、旧版 DOC 暂不支持。

## 阅读

- 上下滚动：直接滑动正文；长书分段载入。
- 左右翻页：到「阅读设置 → 阅读方式」切换。左右轻扫、点屏幕左右两侧，或使用底部上一页／下一页按钮。
- 轻点正文中间：隐藏或恢复阅读工具栏。
- 「目录」：查看识别到的章节和本书书签；「搜索」：查找整本书，最多显示前 100 条匹配。
- 右上角星星：添加／移除当前位置的书签。书库底部「书签」可以查看所有书籍的收藏位置。
- 返回书库后，点击书籍继续上次阅读。段落和段内位置都会保存；改变屏幕方向、字号或阅读方式时会重新排版。

## 阅读设置

设置、目录、书签等底部面板均可按住顶部横条往下拖动关闭；拖动距离不足会自动回弹。也可以点按横条、右上角的叉或面板外的遮罩关闭。面板内容可上下滑动，不显示滚动条。

纸白、暖砂和深夜三个主题，统一圆角控件；字号与行距可以调整。阅读方式也在此处设置。

默认使用内置「霞鹜文楷」，是适合中文阅读的开源楷体风格字体。也可切换系统衬线／黑体，或导入自己有权使用的 TTF / OTF 字体。字体保存后可离线使用。内置字体的完整授权可在阅读设置底部查看，交付包也附有许可文本。

开启「阅读时保持屏幕常亮」后，仅阅读页面保持常亮，回到书库后恢复系统行为。

## 格式与图片

EPUB 按书内 spine 顺序读取，识别 EPUB3 导航和 EPUB2 NCX 目录。DOCX 目录依据段落大纲级别、标题样式及其继承关系，并补充常见「第X章」标题；Word 页眉不是章节目录。

EPUB / DOCX / FB2 支持书内常见位图。图片适配屏宽，较大的位图会缩小以控制内存。SVG 包装中引用的位图可以读取，独立矢量图、公式、图表和外部网络图片不自动加载。HTML 和 Markdown 以可读正文重排；复杂网页排版、完整 Markdown 语法、Word 原始分页与复杂表格布局不保留。

TXT 自动识别 UTF-8、带 BOM 的 UTF-16，UTF-8 不成立时使用 GB18030。

## 书库与删除

导入后保留应用私有的正文和图片副本，原文件移动后仍可阅读。同样内容再次导入会去重。

每本书右上角「⋯ → 从书库删除」，确认后删除这本书在静阅里的副本、阅读进度及书签；手机上的来源文件保留。

书库和阅读记录只保存在这台手机的应用数据里，当前不与 Windows 自动同步。卸载应用或清除应用数据会移除这些记录，请保留自己的原始小说文件。手机换机导出／导入阅读记录尚未提供。
