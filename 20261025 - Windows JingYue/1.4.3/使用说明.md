# 静阅 JingYue 1.4.3

Windows 本地书库与长文阅读器。交付日期：2026-10-26（Asia/Kuala_Lumpur）。

## 开始阅读

双击 `JingYue.exe`，无需安装。请把 `JingYue.exe.config` 和 EXE 放在一起。运行环境为 Windows 10 / 11、.NET Framework 4.8；已在当前电脑验证运行。

首页就是「我的书库」。点击「导入书籍」可同时选择多本书，也可以拖入文件；「导入文件夹」会包含所选目录的子文件夹。你提供的样本目录是 `C:\Users\raymo\OneDrive\小说`，选择它即可导入四个样本文件。

点击书架上的一本书，会恢复到它上次的阅读段落和段内位置。字号或窗口大小改变时会重新排版，画面可能略有差异。返回书库、关闭程序时会保存位置，滚动停止约 0.8 秒也会自动保存。书架显示格式、阅读百分比和上次章节。「继续上次阅读」可打开最近的一本。

## 支持的格式

| 格式 | 支持范围 |
| --- | --- |
| TXT | 中文章节识别；UTF-8、带 BOM 的 UTF-16；UTF-8 无法解码时尝试 GB18030 |
| Markdown（MD、MARKDOWN） | 标题、加粗、行内代码、引用、列表、代码块的基础阅读排版 |
| EPUB 2 / EPUB 3 | 按 spine 顺序读取正文；NCX / 导航目录、章节锚点、书名、作者；支持内嵌位图 |
| DOCX | 读取正文和表格中的文字、内嵌位图；识别段落与样式的大纲级别、样式继承、Heading / 标题 1–9 和中文章节名 |
| HTML / HTM | 提取静态正文、标题、列表和引用，忽略脚本与样式 |
| FB2 | FictionBook 正文、标题、章节 |

以上格式统一重排为适合阅读的文字。EPUB / DOCX 支持书内嵌入的 PNG、JPEG、GIF、BMP、TIFF 等常见位图，SVG 包装中引用的位图也可以显示。独立 SVG / WebP 等当前解码器不支持的图片会显示提示；外部网址图片、图表、公式不自动加载。图片在附近段落进入阅读区域时解码，并使用有上限的内存缓存；单张编码图片上限为 32 MB，超大图片会缩小或显示提示。原书 CSS、分页、复杂表格、脚注跳转和固定版式暂不保留。扫描 PDF 仍不支持。MOBI / AZW3、AZW、PDF、旧版 DOC、RTF 和压缩小说包暂不支持；DRM 加密正文无法读取。HTML 不运行网页脚本。单文件限制为 250 MB；EPUB / DOCX 解压内容上限为 300 MB。

## 书库与数据

数据默认保存在 `%LOCALAPPDATA%\JingYue`：

- `Books`：导入的原始书籍副本，长期保存，不是临时缓存；不会修改来源文件。
- `settings.xml`：书架、原路径、阅读段落、段内偏移、上次章节、书签和阅读设置。
- `settings.xml.bak`：上一次成功保存的索引备份；主索引损坏时会尝试读取。

不需要数据库，也无需联网或登录。相同内容再次导入时按 SHA-256 去重，并保留原有阅读记录。不同格式即使书名相同，仍作为不同书籍。原始文件移动后，已入库的副本仍能阅读。原文件后续修改不会自动同步，需重新导入。书架不受旧版「最近 30 本」限制。

旧版最近阅读记录会显示在新书库；首次点击时会把文件复制入库。备份或迁移时，请关闭程序后复制整个 `%LOCALAPPDATA%\JingYue` 文件夹。书架上每本书右侧都有「删除」按钮。确认后移除书库记录、阅读进度、书签和书库副本，来源文件保留。重新导入会从头开始；删除前请确认是否需要保留阅读记录。自动批量清理暂未提供。

## 操作

- Ctrl+O：导入书籍。
- Ctrl+H：回到书库。
- Ctrl+F：搜索正文；在书库时搜索书名、作者。
- 输入正文关键词后按 Enter：查找下一个匹配段落。
- Ctrl+D：添加或移除当前段落的书签。左侧「书签」查看本书收藏；顶部「我的书签」查看全部书籍的收藏位置。选择一条后点击「跳到书签」，或双击即可跳转。
- F11：进入或离开专注阅读。Escape 也可退出专注模式。
- 阅读设置：三种主题、字体、字号、行距和宽度。TXT 乱码时可切换 UTF-8 / GB18030，再点击「应用编码」。

## 源码与验证

`源码` 目录包含全部 C# 源文件、图标、构建脚本与配置，无第三方依赖。执行 `build.ps1` 生成 EXE；执行 `build.ps1 -Console` 后运行 `JingYue.Tests.exe --self-test` 可进行解析、书库去重、源文件移除、进度持久化、索引备份恢复等测试。可在 `--self-test` 后追加样本文件夹路径。

## 1.3 图文与导航更新

书签入口改为阅读侧栏的独立按钮，顶栏新增跨书籍书签窗口。搜索框使用圆角薄荷配色，随主题切换，带输入提示和聚焦边框。滚动条使用细轨道与圆角滑块，保留轨道翻页、拖动与滚轮操作。图片附着在原有文字段落旁，原有纯文字段落序号不变，沿用现有书库、书签和进度；无需重新导入，关闭旧版后在 1.3 中打开原书即可解析图片。

## 1.4 阅读模式、DOCX 目录与文末图片

在「阅读设置 → 阅读方式」里选择「上下滚动」或「左右翻页」。左右模式提供页脚上一页／下一页箭头，也支持键盘 ← / →、PageUp / PageDown、空格与阅读区域内的鼠标滚轮。搜索框编辑时，方向键仍用于编辑。阅读模式会保存，重新打开后沿用。窗口大小、字号、行距或正文宽度变化时会重新分页，只测量当前页附近的内容。长段落会续到下一页，图片按页面可用高度缩小显示。

DOCX 的目录依据：优先读取段落直接设置的大纲级别，再读取段落样式及其 basedOn 继承的大纲级别；大纲 1–9 级进入目录，正文级别排除。也识别 Heading1–9 / 标题1–9，并对短中文章标题作补充识别。自定义样式名不必包含 Heading；例如 HedingTitle 设置大纲 1 级就会进入目录。单纯加粗、字号变大、重复页眉／页脚不会自动成为目录。

图片改为独立的虚拟阅读项，预读常见位图尺寸，预留稳定高度。加载和回收图片不会使内容高度反复改变；文末多图不再合并为一个巨大段落。上下模式的进度同时计入文字与图片，并在滚动到底部时显示 100%；分页模式在最后一页显示 100%。已验证末尾 20 张竖图从 100% 向上滚动后不会回弹。

原有书库和段落书签保留。旧版位置按相应段落接续，新版开始保存具体文字／图片项、段内偏移及分页字符位置，无需重新导入。你提供的 DOCX 缓存样本（19,406 字符、554 段）已恢复识别出 5 个目录项。原始文档由 Word 占用时，测试只读取书库副本，没有修改来源文件。

## 1.4.1 界面调整

阅读方式入口统一移入阅读设置，正文区域顶部不再显示模式切换栏。左右翻页时仍保留页脚箭头、方向键和鼠标滚轮操作，阅读方式与进度照常保存。

## 1.4.2 统一圆角视觉

阅读方式、字体与编码下拉框统一使用圆角外框、自绘箭头和圆角展开菜单；选项高亮与边框随主题切换。设置滑杆改用圆形滑块与圆头轨道。目录、书签、最近阅读、书架选中高亮也采用圆角容器，替换默认方形焦点框。应用内确认／提示窗使用同一套圆角按钮，删除仍需确认，取消不改变书库。设置窗口适当加高，小屏幕保留滚动。纸白、暖砂、深夜主题均已检查，字体菜单选择、收起与取消删除已实测。

## 1.4.3 搜索框修正

修正搜索输入框模板重复计算内边距的问题。原来光标与实际输入文字比提示语多向右缩进约 15 像素，空输入框也被额外撑高；现在光标、提示语和输入文字对齐，搜索框恢复正常高度。书库搜索和全文搜索共用此修正。

直接运行新版即可使用原有书库、阅读位置、书签和设置，无需重新导入。已通过真实 WPF 布局检查与现有解析、书库、图片及分页检查，并在隔离预览窗口实际检查搜索筛选和光标位置。
