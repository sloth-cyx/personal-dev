# Windows 1.5.0 构建

PowerShell 中运行 .\build.ps1 生成 JingYue.exe，需要 Windows 上的 .NET Framework 4.8，不需要第三方依赖。

运行 .\build.ps1 -Console，然后运行 .\JingYue.Tests.exe --self-test 可验证解析、书库、搜索框、分页及章节联动。章节联动测试使用临时书库和真实 WPF 控件，在屏幕外验证恢复位置、目录点击、滚动、章节高亮、长目录可见性和无章节情况，不读取用户书库。

图标随编译参数 /win32icon 嵌入，ICO 包含 16、24、32、48、64、128、256 像素。可编辑 SVG 和 PNG 预览随源码提供；create-icon.cjs 可使用 Node 重新生成原标识的多尺寸图标；verify-icon.cjs 检查实际 EXE 的图标资源。正常构建和运行不需要 Node。
