# Android 1.0.2

交付日期：2026-10-26（Asia/Kuala_Lumpur）。

书库搜索框使用统一的外层焦点边框，移除输入框内部重叠的焦点框和系统重复的清除按钮。仅保留一个清除按钮，搜索内容为空时自动隐藏。

底部面板顶部横条的触摸区域已扩大：按住往下拖动，面板会跟随手指，超过关闭距离或快速下拉后关闭；拖动距离不足或触摸被取消时自动回弹。也支持点按横条关闭。设置、章节目录、本书书签、搜索结果、字体许可等共用面板统一生效，内容仍可正常上下滑动，滚动条继续隐藏。

版本代码提升到 10002，沿用 1.0.0 / 1.0.1 的签名。直接安装升级即可保留书库、书签和阅读记录，无需卸载旧版。

本次检查了小屏和常规手机尺寸下搜索框的焦点状态、清除操作，以及底部面板的跟手拖动、短拖回弹、触摸取消、点按关闭、内容滚动、关闭动画期间打开其他面板等情况。原有阅读、分页、图片尾部、书签与删除检查也已通过。APK 已重新编译并通过签名检查。

用户已安装使用过此前版本；此次新增界面改动在 Chrome 手机尺寸环境检查，未新增 Android 真机测试。
