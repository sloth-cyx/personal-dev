ScreenPen 1.1 — 屏幕画笔
发布日期：2026-11-05（Asia/Kuala_Lumpur）

启动
双击 ScreenPen.exe，无需安装。请先退出正在运行的旧版。
Windows 10/11 64 位，使用系统的 .NET Framework 桌面组件。

工具
画笔 / 荧光笔：按住鼠标左键画线或圈选，可选择颜色和粗细。
激光笔：移动鼠标出现红色发光轨迹，约 0.75 秒后消失，不留下永久笔迹。
橡皮擦：按住左键拖动，局部擦除笔迹；擦到文字或便签时删除整项。粗细也影响擦除范围。
文字：先选颜色，点击屏幕空白处输入文字，可选择字号；Ctrl+Enter 确定，Esc 取消。
便签：点击空白处输入多行内容，显示黄色底板，便于标记重点。
移动：拖动文字或便签移动；双击修改内容和字号。文字/便签工具也支持拖动、双击编辑。
撤销 / 重做：恢复前一步编辑，最多保留 50 个撤销步骤。清屏同样可撤销。
隐藏批注：临时隐藏全部笔迹、文字和便签，并恢复正常鼠标。再次点击恢复原内容。
收起工具栏：只隐藏工具栏，批注继续显示。
全屏截图：选择保存路径，工具栏临时隐藏后截取当前整个桌面，保存为 PNG；包含可见批注，不包含工具栏与保存窗口。多屏合并为一张图片。

快捷键
F8               在当前工具和正常鼠标之间切换；批注已隐藏时会恢复批注
F9               清屏（可以撤销）
F10 / 鼠标右键    撤销；右键仅在批注模式生效
Ctrl+Alt+B       隐藏 / 恢复全部批注
Ctrl+Alt+H       收起 / 展开工具栏
Ctrl+Alt+S       全屏截图
Esc              工具栏有焦点时切回正常鼠标；编辑文字时取消输入

补充
激光笔为临时指示效果，截图时不保留临时激光轨迹。
隐藏批注后截图，会截取没有批注的当前画面。
批注固定在屏幕位置，底层窗口滚动或移动时不会跟随其内容。
关闭程序后批注不保存，需要留存时请先截图。
显示器配置改变时会清空当前批注并适配桌面；文字过长会折行，并在显示高度上限处省略。
快捷键若被其他软件占用，工具栏会显示提示；可以改用按钮。部分键盘需配合 Fn 使用 F8/F9/F10。
建议会议软件分享“整个屏幕”，先确认对方看得到批注。不同软件的窗口捕获和受保护内容可能表现不同。
当前电脑已验证，混合缩放比例的多显示器组合和不同会议软件仍需实际确认。

源码和图标
source\ScreenPen.cs：完整源码，内置 --self-test 数据与渲染检查。
source\build.ps1：编译脚本，自动嵌入专属 ICO 和 PNG 窗口图标。
source\ScreenPen.svg：可编辑图标，沿用旧版视觉标识。
source\ScreenPen.ico：多尺寸图标；source\ScreenPen.png：预览。
--test 用于有限画布的手工验证，正常使用无需任何参数。
