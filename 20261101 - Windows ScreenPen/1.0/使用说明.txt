ScreenPen 屏幕画笔 — v1.0
交付日期：2026-11-01（Asia/Kuala_Lumpur）

用途
双击 ScreenPen.exe 后，鼠标变为笔，可以直接在当前屏幕上画线、圈选和标记。
适用于分享整个屏幕时讲解内容。无需安装，无需联网。

快速使用
1. 双击 ScreenPen.exe，默认进入画笔模式。
2. 按住鼠标左键画线或画圈。
3. 选择“荧光笔”可画半透明标记；色点可选择颜色，粗细下拉框可改变笔宽。
4. 按 F8，或点击工具栏最左侧的模式按钮，恢复正常鼠标操作。批注继续保留。
5. 再按 F8 可继续绘画。
6. 点击“退出”关闭程序，所有笔迹随之清除。

快捷键
F8                切换画笔 / 鼠标模式
F9                清除全部笔迹
F10               撤销最后一笔
鼠标右键           画笔模式下撤销最后一笔
Ctrl + Alt + H    隐藏 / 显示工具栏（批注继续保留）
Esc               工具栏有焦点时退出画笔模式

工具栏
拖动 ScreenPen 标题可以移动工具栏。
隐藏工具栏之前，建议先确认 Ctrl+Alt+H 在你的电脑上可用。
若快捷键被其他程序占用，工具栏会显示提示，可改用对应按钮。
部分键盘需要配合 Fn 使用 F8、F9、F10。

分享屏幕
建议选择“整个屏幕 / 显示器”，并先请对方确认能看到笔迹。
只分享某个应用窗口时，会议软件可能不会捕获覆盖在上方的批注层。
本版本没有与会议软件单独集成，未验证各会议软件的捕获行为。

使用范围
Windows 10 / 11，64 位，需系统已有 .NET Framework 4.x 桌面组件。
当前电脑已成功编译和启动。
画笔和荧光笔、6 种颜色、4 档粗细、撤销、清屏、浮动工具栏。
批注固定在屏幕位置；网页滚动或切换窗口时，笔迹不会跟着原来的内容移动。
显示器配置或分辨率改变时，会清空批注并重新适配桌面。
本版本没有保存批注、文字输入、橡皮擦及自动吸附圆形等功能。
多屏覆盖按 Windows 虚拟桌面实现；不同缩放比例的多屏配置仍需实际验证。

源码
source\ScreenPen.cs 为完整程序源码。
source\build.ps1 为编译脚本，可在装有 .NET Framework 4.x 编译器的 64 位 Windows 上运行。
构建脚本在 source 文件夹内生成 ScreenPen.exe，交付根目录中的 EXE 不会被它覆盖。
